# 数据准备与可复现边界

| 名称 | 行数 | 属性数 | 输入与处理 |
|---|---:|---:|---|
| Bank | 41,176 | 18 | 历史整数表的精确副本，随仓库压缩保存 |
| DefaultCredit | 30,000 | 23 | UCI XLS，去 ID 和分类标签，保留类别值，数值列保留零值类别并对非零值十分位分箱 |
| CensusIncomeKDD | 299,285 | 40 | UCI train/test 合并，去实例权重和收入标签，类别编码，数值分箱 |
| MiniBooNE | 130,064 | 50 | UCI 测量值逐列十分位分箱，标签不参与挖掘 |
| PokerHand | 1,025,010 | 10 | UCI train/test 合并，去手牌分类标签，保留花色 1–4 和点数 1–13 |
| LetterRecognition | 20,000 | 16 | 保留原整数特征，去字母分类标签 |
| Toy | 1,200 | 8 | seed=2026 的相关二元属性，仅用于验证流程 |

所有主入口默认挖掘长度 1–4 的合法项集，同一项集中一个属性至多出现一个值。
正式数据下载由 `workflows/prepare.py` 管理。下载记录、SHA-256、分箱边界和类别映射随整数 CSV 保存。
Census 的转换复用 `experiments/prepare_large_data.py`，MiniBooNE 的编码复用原编码函数。

Bank 的历史 raw→integer 脚本没有保留下来。为复现当前实验表示，提供 `data/reference/Bank.csv.gz`
及校验和，解压后内容与历史实验完全一致。当前无法独立确认这 18 列与官方各字段、标签的完整映射，
因此不将该副本描述为重新验证过的官方预处理。需要重新定义 Bank 表示时，应另用数据集名称和结果目录。
来源页面：https://archive.ics.uci.edu/dataset/222/bank+marketing 。

数据变换在纵向划分之前进行。实验 4 在完整表中按 seed 抽样。实验 5 将若干原属性组合成元组值，
再编码为一个新属性，减少属性数但保留元组信息。实验 6 按 seed 将每个属性的取值归到较少类别。
全局真值在变换后的同一张表上重新计算，不能直接复用未变换数据的 Top-k。

这些公开基准数据的全表分箱边界、值域和元组编码视为公开预处理。
若源数据本身是私有的，当前代码不为发布这些预处理信息自动提供额外 DP 保护。

自有整数 CSV 可通过 `privfim run --csv ...` 输入。客户端共享行顺序是输入前提，
不同客户端用户对齐/PSI 不在该预处理器内实现。
